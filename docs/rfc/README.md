## RFC Process

1. **Draft** - Initial proposal, open for discussion
2. **Review** - Under review by maintainers
3. **Accepted** - Approved for implementation
4. **Implemented** - Feature has been implemented
5. **Deprecated** - Feature is being phased out

## Contributing

To propose a new feature:
1. Create a new RFC document using the template
2. Open a pull request with the `[RFC]` prefix
3. Discuss and refine the proposal
4. Await maintainer approval
